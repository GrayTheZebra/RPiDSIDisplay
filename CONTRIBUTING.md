# Contributing

Please open an issue describing the hardware and observed behavior before a
large change. Include exact Arduino core/IDF versions, board revision, panel
model, custom timings, serial output and a photo for display issues.

Keep changes focused. Preserve default timing unless supported by documented
hardware tests. Compile every example and run the hardware checklist in
TESTING.md for initialization, drawing or timing changes. Private ESP-IDF
layout assumptions require review whenever the supported core changes.

Contributions must be compatible with GPL-2.0-only. Preserve upstream notices;
do not include credentials, personal data or build artifacts in reports.
